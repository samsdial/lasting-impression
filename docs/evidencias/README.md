# Evidencias visuales

Esta carpeta almacena las capturas de pantalla que respaldan los criterios de evaluación de la Etapa 1.

## Archivos esperados

- `comunicacion.png` — captura de una interacción real del equipo en el canal de comunicación (Microsoft Teams, Discord, u otra plataforma acordada). No basta con mostrar el grupo creado: debe verse una conversación con contenido real.
- Otras capturas que respalden los criterios de la rúbrica (opcional).

## Nota sobre privacidad

Antes de subir capturas, revisar que no contengan información sensible de terceros (correos, números de teléfono, etc.).
